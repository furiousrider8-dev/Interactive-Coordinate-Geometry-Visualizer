Line — slope-intercept y = mx + b

HOW IT WORKS
Every straight line can be written as y = mx + b.
m (slope) — rise over run. Positive = tilts up right, negative = tilts down right. m = 0 is horizontal.
b (y-intercept) — where the line crosses the y-axis (at x = 0).
x-intercept — where y = 0, found at x = −b/m. Shown as a dot on the axis.
Two-point form — enter any two points and m and b are computed automatically using m = (y₂−y₁)/(x₂−x₁).
Parallel lines share the same m. Perpendicular lines have slopes that multiply to −1 (m₂ = −1/m₁).

Wave parameters

HOW IT WORKS
All waves here follow the form y = A · wave(ωx + φ) + D.
A — amplitude: peak height above (and below) the midline. Doubling A doubles the wave's height.
ω — frequency: how many full cycles fit in 2π units. Period = 2π / ω, shown live below the sliders.
φ — phase: shifts the wave left/right. φ = π/2 turns a sine into a cosine.
D — vertical shift: moves the whole wave up or down, changing the midline from y = 0 to y = D.
Sawtooth / square / triangle are non-sinusoidal periodic waves — useful for understanding Fourier series decomposition.

General identities & reference

▸ Pythagorean
sin²x + cos²x = 1
1 + tan²x = sec²x
1 + cot²x = csc²x
▸ Sum & Difference
sin(a ± b) = sin a cos b ± cos a sin b
cos(a ± b) = cos a cos b ∓ sin a sin b
tan(a ± b) = (tan a ± tan b) / (1 ∓ tan a tan b)
▸ Double Angle
sin(2x) = 2 sin x cos x
cos(2x) = cos²x − sin²x
cos(2x) = 2cos²x − 1 = 1 − 2sin²x
tan(2x) = 2 tan x / (1 − tan²x)
▸ Half Angle
sin²x = (1 − cos 2x) / 2
cos²x = (1 + cos 2x) / 2
tan(x/2) = sin x / (1 + cos x)
▸ Product to Sum
sin a sin b = ½[cos(a−b) − cos(a+b)]
cos a cos b = ½[cos(a−b) + cos(a+b)]
sin a cos b = ½[sin(a+b) + sin(a−b)]
▸ Euler & Complex
e^(ix) = cos x + i sin x
e^(iπ) + 1 = 0Euler's identity
cos x = (e^(ix) + e^(−ix)) / 2
sin x = (e^(ix) − e^(−ix)) / 2i
▸ Derivatives
d/dx sin x = cos x
d/dx cos x = −sin x
d/dx tan x = sec²x
d/dx eˣ = eˣ
d/dx ln x = 1/x
d/dx xⁿ = n·xⁿ⁻¹power rule
d/dx f(g(x)) = f′(g(x))·g′(x)chain rule
▸ Lines & Slopes
slope m = Δy / Δx = (y₂−y₁)/(x₂−x₁)
y = mx + bslope-intercept

▸ Waves
y = A·sin(ωx + φ) + D
period T = 2π / ω
frequency f = 1 / T = ω / 2π
phase shift = −φ / ω

▸ Conic Sections
circle: x² + y² = r²
ellipse: x²/a² + y²/b² = 1
hyperbola: x²/a² − y²/b² = 1
parabola: y = ax² + bx + c
Tip: plot conics in parametric mode — circle: r·cos(t), r·sin(t) — ellipse: a·cos(t), b·sin(t)

Direction of Travel

This arrow shows the direction in which the curve is traced as the parameter t increases from 0 toward its maximum.

Why it matters
Two different curves can have the same shape but opposite directions of traversal. For example, a clockwise circle and a counter-clockwise circle look identical, but their direction vectors and tangents point opposite ways — critical in physics, animation paths, and vector calculus (e.g. line integrals change sign with direction).
Try it
Compare x(t)=cos(t), y(t)=sin(t) (counter-clockwise) vs x(t)=cos(t), y(t)=−sin(t) (clockwise) — the arrow flips.
The arrow is placed at t≈50% of the curve's range
